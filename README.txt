BLOOD FIGHT - AS1
Offline Android fighting game project (Godot 4.x, GDScript).

WHAT'S INCLUDED
- 12 fighter roster with distinct names, titles and color identities.
- Start with Rukhan. Defeating each campaign challenger unlocks that fighter permanently.
- 11 sequential fights, with the final boss as the last opponent; campaign progress is saved locally.
- Best-of-three rounds, 99-second round timer, health and special-power bars.
- Touch controls: left, right, jump, block, punch, kick and special.
- Opponent AI becomes faster and more damaging as campaign fights advance.
- Offline play; no account or internet connection required.

OPEN THE PROJECT
1. Extract this ZIP into a folder named AS1_Blood_Fight.
2. Open Godot 4.x Editor and choose Import.
3. Select the project.godot file inside the extracted folder.
4. Open the project and press Play.

ANDROID EXPORT
This package is a Godot source project, not an APK. To create an installable APK, open it in Godot on a computer with Android export templates, Android SDK and JDK configured. Choose Project > Export, add Android, configure the package name and signing, then Export Project. Test the exported APK on the target phone.

NOTE
The fighters are stylized procedural placeholder drawings rather than finished hand-drawn animation assets. Gameplay systems are implemented in GDScript; test on your Godot version before release. The project targets landscape orientation and the Compatibility renderer for broad Android support.
